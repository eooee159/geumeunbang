🔗 구글 스프레드시트 연동 설정

① Google Apps Script 배포 URL 입력

② GAS 서버 코드 설정 방법

1. script.google.com 접속 → 새 프로젝트 생성
2. 금은방_GAS_서버.js 파일의 내용을 붙여넣기
3. 코드 상단 SHEET_ID에 구글 스프레드시트 ID 입력
   (스프레드시트 URL: docs.google.com/spreadsheets/d/시트ID/edit)
4. [배포] → [새 배포] → 유형: 웹 앱 선택
5. 실행 계정: 나 / 액세스: 모든 사용자 선택 후 배포
6. 생성된 URL을 위 입력란에 붙여넣기 → 저장

③ 데이터 동기화

※ 불러오기: 구글 시트의 데이터를 현재 앱에 덮어씁니다
※ 저장: 현재 앱의 데이터를 구글 시트에 덮어씁니다
