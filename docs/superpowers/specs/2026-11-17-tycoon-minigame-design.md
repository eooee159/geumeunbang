# K-타이쿤 미니게임 설계 (요약)

## 의도
캐피탈리즘 2류 경영 시뮬레이션의 핵심 재미(생산-판매-경쟁-인수)를 가볍게 즐기는 단일 HTML 미니게임. 금은방 앱과 무관.

## 목표 / 비목표
- 목표: 도시 10, 기업 10(플레이어 1 + AI 9), 월 단위 턴, 10년 후 기업가치 1위.
- 비목표: 원작 재현(이름·그래픽·고유 콘텐츠 사용 안 함), 복잡한 공급망, 멀티플레이.
- 안티골: 조작이 번거로워 한 판이 무거워지는 것.

## 접근
- 채택: 순수 HTML/JS 단일 파일 `tycoon.html` (기존 저장소 방식과 동일, Chart.js CDN).
- 기각: 프레임워크/빌드 도입(저장소 성격과 불일치), 기존 index.html 내 탭 추가(무관한 앱 오염).

## 핵심 규칙
- 제품 6종(식품, 의류, 화장품, 스마트폰, 가전, 자동차). 공장 = 생산, 매장 = 도시별 판매.
- 도시 점유율 = 매장 수 × 품질 × 브랜드 × 가격 경쟁력. 재고·매장 처리량 한도 존재.
- R&D → 품질, 광고 → 브랜드. 경기·원자재 지수와 랜덤 이벤트.
- 주식: 기업가치 기반 주가, 지분 매수·매도, 배당, 50% 이상 보유 시 잔여 지분 매입 후 합병.
- 현금 부족 시 자동 대출, 한도 초과로 3개월 연속 적자 현금이면 파산.
- 진행 상황 localStorage 자동 저장. 자동 진행(1x/2x).
